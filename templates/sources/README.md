Record images, transcriptions and research dossiers. Name files by date, event, place and person, for example `1717-04-burials-Musterdorf-Johann-and-Maria-Schmidt.jpg`, with a sidecar note of the same name in `.md` giving the full citation, a "Compiled by" line and the first words of the entry. Session dossiers take the date first: `2026-11-01-schmidt-1651-close-reading.md`. See "Sources and images" in `AGENTS.md`.
